## 牌姿について（重要）

本インデックスには**各問題の牌姿（河・副露・手牌・ドラ・選択肢の牌）を転記していない**。写真から 1 枚ずつ正確に読み取る必要があり、誤転記のまま `questions.json` に入れると問題の正しさが崩れるため、品質優先のルールに従って見送った。

- 未組み込み 29 問を実際にアプリへ入れる場合は、**写真 60 枚（IMG_8381〜8407 と IMG_0007〜0040）が必要**
- 写真は `/root/company` フォルダの削除で失われる。第三者著作物（市販書籍のページ撮影）のため GitHub へは保存しない方針
- 書籍が手元にあれば再撮影で復元できる
