## 牌姿の転記について（重要）

2026-10-12 の追加では、写真を原寸でクロップして**牌姿（自分の手牌・相手の捨て牌・副露・ドラ・点数）も転記した**。ただし精度には差がある。

- **確度が高い**: 設問文・選択肢・正解・格言・解説（本文の大きな文字から読み取り）、字牌と萬子（漢字で判別可能）、副露の種類（設問文に明記）
- **要確認**: 筒子・索子の数牌（丸と棒の数で判別するため誤読の可能性がある）、相手の河の字牌、巡目（図に明記が無いため並び順から機械付番）
- そのため追加した 28 問はすべて `needsReview: true` とし、`notes` に「どこが確実でどこが推定か」を 1 問ずつ明記した。`sourceImages` に出典写真のファイル名も記録している
- 鳴き読みドリル 64・65・66 などで対面のポン牌が図から読み切れなかった箇所は、推定である旨を notes に記載した
- 書籍は選択式ではないため、誤答選択肢は解答ページが論じた選択肢から編集的に構成した（既存 q011-q036 と同じ方針）

**写真は `/root/company` フォルダの削除で失われる**。第三者著作物（市販書籍のページ撮影）のため GitHub へは保存しない方針。`needsReview` の精査を写真で行いたい場合は、削除前に写真 60 枚（IMG_8381〜8407 と IMG_0007〜0040）を退避する必要がある。書籍が手元にあれば再撮影でも復元できる。
